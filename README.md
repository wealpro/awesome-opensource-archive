## 🚀 为什么用数字档案

- **免克隆**：每个项目已打包为 zip，网盘直接转存下载，省去逐个 git clone
- **带中文档案**：每个 zip 内含「仓库信息.txt」（项目名/作者/许可证/简介）
- **全部 OSI 许可**：MIT / Apache / GPL / BSD 等，可安心学习二次开发
- **持续更新**：每周新增批次，Star 本仓库获取更新通知
